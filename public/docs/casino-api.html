🎰 JuanAI Casino API

Public documentationNo secret required to read

Purpose

For casino/betting operators connecting their own player wallet to JuanAI casino games. JuanAI is the integration layer; the operator remains the authority for player funds.

Credentials

Casino operators use a separate credential pair:

API key: jcas_...
API secret: jcas_secret_...

These credentials are not the football jsk_... keys and are not Game API credentials.

Wallet ownership

The operator's wallet is authoritative. JuanAI must call the operator wallet for balance, debit, credit, refund and rollback. JuanAI does not become the player's balance ledger.

Core API

POST /api/v1/casino/session
GET  /api/v1/casino/games
POST /api/v1/casino/wallet/balance
POST /api/v1/casino/wallet/debit
POST /api/v1/casino/wallet/credit
POST /api/v1/casino/wallet/refund
POST /api/v1/casino/wallet/rollback

Security

Keep the secret server-side. Sign requests/callbacks with the configured HMAC secret. Use unique transaction IDs for idempotency. Never put the secret in browser JavaScript.

Casino API Pro

Casino API Pro is a separate provider integration inside JuanAI. Its credentials stay server-side. The provider session currency is controlled by CASINO_API_PRO_CURRENCY; this build defaults to KES and can automatically add that currency to the provider business account when permitted.
