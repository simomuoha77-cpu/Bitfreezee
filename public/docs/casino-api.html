Casino API

Authentication

X-JuanAI-Key: YOUR_CASINO_KEY
X-JuanAI-Secret: YOUR_CASINO_SECRET

Use the separate Casino Developer credential. Never expose the secret in browser JavaScript.

GET /api/developer/casino/games

GET /api/developer/casino/games

Returns the complete JuanAI casino catalogue: JuanAI real-money games plus AS Tech games currently exposed by JuanAI. AS Tech catalogue games are demo-only in this integration until an authorized real-money partner integration is configured.

GET /api/developer/casino/state/:gameId

GET /api/developer/casino/state/aviator
GET /api/developer/casino/state/jetx

Returns the current round state and crash history without exposing a player balance.

POST /api/developer/casino/wallet/register

Content-Type: application/json
X-JuanAI-Key: YOUR_CASINO_KEY
X-JuanAI-Secret: YOUR_CASINO_SECRET

{"baseUrl":"https://your-betting-site.example"}

Registers the authenticated developer credential's wallet callback base URL. The Developer API secret is used server-side as the HMAC signing secret for the wallet channel.

GET /api/developer/casino/balance?userId=...

POST /api/developer/casino/bet

{"userId":"USER_ID","gameId":"aviator","slot":1,"stake":10}

GET /api/developer/casino/bet/:betId?userId=...

POST /api/developer/casino/bet/:betId/cashout

{"userId":"USER_ID"}

These are server-to-server real-money operations. SafariBet's own wallet remains the balance ledger; JuanAi calls the registered wallet for debit/credit/balance.

Games

The JuanAi casino integration currently exposes Aviator and JetX. Unsupported or placeholder games are not returned by this API.
