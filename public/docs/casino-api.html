GET /api/developer/casino/providers

X-JuanAI-Key: YOUR_CASINO_KEY
X-JuanAI-Secret: YOUR_CASINO_SECRET

Returns the provider catalogue through JuanAi's existing AS Tech public integration.

GET /api/developer/casino/games

GET /api/developer/casino/games?providerCode=spribe&search=Aviator&page=1
X-JuanAI-Key: YOUR_CASINO_KEY
X-JuanAI-Secret: YOUR_CASINO_SECRET

providerCode, search and page are supported by the existing AS Tech catalogue adapter. Omit providerCode for the full catalogue.

This is the existing AS Tech public zero-balance demo launch. It is not a production real-money wallet integration.

Production wallet

Balance, bet, win and rollback are not faked by this Developer API. Wallet operations are pending until the production provider transaction/callback integration is implemented and tested. The existing JuanAi/SafariBet wallet bridge remains intact.

AS Tech protection

External developers receive JuanAi credentials only. AS Tech internal server-function IDs, provider implementation details and credentials remain server-side.
