Casino API

Authentication

X-JuanAI-Key: YOUR_CASINO_KEY
X-JuanAI-Secret: YOUR_CASINO_SECRET

Use the separate Casino Developer credential. Never expose the secret in browser JavaScript.

GET /api/developer/casino/games

GET /api/developer/casino/games

Returns the complete JuanAI casino catalogue. AS Tech games are discovered from all available providers/pages and are not restricted to Aviator or JetX.

GET /api/developer/casino/providers

GET /api/developer/casino/providers

Returns the provider catalogue available through the JuanAI AS Tech adapter.

POST /api/developer/casino/launch

Content-Type: application/json
X-JuanAI-Key: YOUR_CASINO_KEY
X-JuanAI-Secret: YOUR_CASINO_SECRET

{"gameId":"spribe:737"}

Launches any AS Tech catalogue game through JuanAI and returns the provider demo URL. The current public AS Tech integration is demo-only, so the response explicitly contains mode: demo and realMoney: false.

POST /api/developer/casino/demo-launch

Backward-compatible alias for the universal launch endpoint.

JuanAI-owned real-money games

GET /api/developer/casino/balance?userId=USER_ID
POST /api/developer/casino/bet
GET /api/developer/casino/bet/:betId?userId=USER_ID
POST /api/developer/casino/bet/:betId/cashout

These routes apply to JuanAI-owned real-money game integrations. They are separate from the public AS Tech demo catalogue.

Production AS Tech wallet

JuanAI does not fake a production AS Tech wallet/session bridge. Real-money AS Tech play requires an authorized provider production contract, credentials and signed wallet/callback specification. Until that is configured, AS Tech games remain correctly marked demo-only.
