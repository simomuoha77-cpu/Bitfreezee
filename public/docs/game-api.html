🎮 JuanAI Game API

Public documentationNo secret required to read

Purpose

For independent game providers connecting games to JuanAI casino operators. This API is separate from the Casino API.

Credentials

Game providers use their own credential pair:

API key: jgam_...
API secret: jgam_secret_...

Create these credentials from JuanAI Admin → API Keys. The secret is shown once at creation and is never included in the credentials list. Never reuse Casino API credentials here.

Core API

POST /api/v1/game/register
GET  /api/v1/game/catalogue
POST /api/v1/game/session
POST /api/v1/game/callback/win
POST /api/v1/game/callback/refund
POST /api/v1/game/callback/rollback

Settlement

Games identify the player, session, round and transaction. Wallet movement is idempotent and must use unique transaction IDs. Operators remain the wallet authority.

Security

Game API secrets are server-side only. Use HMAC signatures for callbacks and rotate/revoke credentials independently from Casino API credentials.
