JuanAI Game API

Separate integration API for game providers/platforms. Game integrations receive jgam_... API keys and separate secrets.

Important: game credentials are separate from Casino API credentials. A jgam_... key cannot call Casino API endpoints.

Authentication

X-JuanAI-Game-Key: jgam_...
X-JuanAI-Timestamp: 1760000000
X-JuanAI-Signature: HMAC_SHA256(secret, timestamp + "." + rawBody)

Endpoints

GET /api/v1/games/catalog
GET /api/v1/games/:gameId

Catalogue response

The catalogue contains only games currently registered by JuanAI's casino integration. Do not treat a game as live merely because a provider advertises it; JuanAI only lists registered active games.

Wallet boundary

JuanAI games do not create a second player wallet. For real-money casino play, the betting site's wallet is authoritative and the Casino API handles the debit/credit/refund transaction flow.
