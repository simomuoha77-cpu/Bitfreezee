Football API

GET /api/developer/football/fixtures

Returns JuanAi-normalized fixture data. The upstream football provider architecture remains internal.

GET /api/developer/football/fixtures?days=0&sport=football

Headers:
X-JuanAI-Key: YOUR_FOOTBALL_KEY
X-JuanAI-Secret: YOUR_FOOTBALL_SECRET

Parameters: days (default 0), sport (football, basketball, tennis, hockey, cricket, volleyball, rugby, handball), includeFinished=1 to include finished matches.

GET /api/developer/football/competitions

GET /api/developer/football/competitions
X-JuanAI-Key: YOUR_FOOTBALL_KEY
X-JuanAI-Secret: YOUR_FOOTBALL_SECRET

Returns the competitions available through JuanAi's existing football data layer.

Response

{
  "success": true,
  "sport": "football",
  "days": 0,
  "fetchedAt": "...",
  "matches": []
}

Important

Do not use Football credentials against Casino endpoints. Do not expose upstream provider keys, URLs, MongoDB credentials or AI-provider credentials to external developers.
